### 1. GPT-1

GPT-1 miało taki sam cel jak oryginał: zrobić pierwszy działający model i uczyć sie z niego
powstał na początku roku 2026

jego rozumowanie było trudne do opanowania

### 2. GPT-1Pro

GPT-1Pro to lepsza wersja GPT-1, 
ulepszony Attention, Multi Head Attention(MHA),

minus: nie da sie trenować(algorytm nie był zrobiony, a już nie miałem czasu na dalsze budowaniu go)

### 3. GPT-1ASTRA

GPT-1ASTRA to sama nazwa wskazuje, najlepszy model z tej generacji
miał on prosty i dobry trening, ultra dużo personalizjacji działania
był wykorzystawy w jednej z mojej grze

potrafi łączyć fakty i mieć rozumowanie
n.p.:

User: "Why we see the lightning before we hear it?"
Assistant może odpowiedzieć: "Becouse Light is faster than sound."
